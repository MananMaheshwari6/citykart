# 🛒 CityKart

CityKart is a modern web-based platform designed to simplify buying and selling within a city. It provides users with a seamless experience to browse products, list items, and connect with local buyers and sellers efficiently.

---

## 🚀 Features

- 🔍 Browse products available in your city
- 🛍️ List items for sale بسهولة
- 👤 User authentication (login/signup)
- 📦 Product management (add, update, delete)
- 🔎 Search and filter functionality
- 💬 Easy communication between buyers and sellers
- 📱 Responsive design for all devices

---

## 🛠️ Tech Stack

**Frontend:**
- HTML

- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB
